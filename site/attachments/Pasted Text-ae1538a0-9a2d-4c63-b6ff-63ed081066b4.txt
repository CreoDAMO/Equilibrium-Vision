# 4. The Rust core
 
The Rust portion contains the deepest protocol machinery.
 
Important components include:
 
### `stationary_solver.rs`
 
The current block-discovery solver.
 
It calculates the implemented residual, performs iterative optimization, and produces candidate:
 
 
- nonce
 
- residual
 
- related solver quantities.
 

 
This is currently part of the **real production mining path**.
 
***
 
### `consensus.rs`
 
Current fork-choice logic compares cumulative stationarity residual.
 
Conceptually:
 
\[
R(F)=\sum_{B\in F}R_B
\]
 
and the lower cumulative residual history is selected.
 
So:
 
\[
F^*=\arg\min_F R(F)
\]
 
That is an implemented protocol behavior.
 
***
 
### `consensus-api.rs`
 
This is the Rust API boundary for:
 
 
- solving
 
- proving
 
- verifying
 
- warmup.
 

 
Critically, it calls:
 
```text

```
 
for block solving.
