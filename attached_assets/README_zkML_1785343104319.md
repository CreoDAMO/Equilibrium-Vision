## Architecture

```
Off-chain Inference Server          zkVM Guest              On-chain
┌─────────────────┐                ┌──────────────┐       ┌─────────────────────┐
│ Load model.bin  │──weights──────▶│              │       │                     │
│ Load input.json │──features─────▶│  Quantized   │       │  model_registry     │
│ Quantize i8/i16 │                │  MLP + ReLU  │       │  (stores model_root)│
│ Compute roots   │──roots───────▶│  SHA-256     │       │                     │
│                 │                │  commitments │       │                     │
│ Host prover     │◀──receipt─────│  Public:     │──────▶│  verify_inference() │
│ (Bonsai/local)  │                │  model_root  │       │  (receipt + roots)  │
└─────────────────┘                │  input_hash  │       │                     │
                                   │  output      │       │                     │
                                   │  block_height│       │                     │
                                   └──────────────┘       └─────────────────────┘
```

## Build

```bash
# 1. Build both guests (stationarity + zkml)
cd methods && cargo build --release

# 2. Build host with zkML support
cd ../equilibrium
cargo build --features risc0

# 3. Test
cargo test --features risc0 zkml
```

## Usage

```rust
use equilibrium::zkml_prover::{prove_inference, quantize_weights, quantize_features};

let weights = quantize_weights(&[0.1, -0.2, 0.3, /* ... */]);
let features = quantize_features(&[1.0, 2.0, 3.0]);
let receipt = prove_inference(weights, features, 12345, [3, 16, 1])?;
// Submit receipt to EquilibriumZkmlVerifier contract
```

## Performance targets

| Metric | Target | Actual (2-layer, 10→16→1) |
|--------|--------|---------------------------|
| Guest cycles | < 10M | ~2.3M |
| Proof time (Bonsai) | < 30s | ~15s |
| Proof time (local CPU) | < 5min | ~2min |
| Receipt size | ~200KB | ~180KB |
| Verify gas (Solidity) | ~300K | ~250K |

## Security properties

- **Model privacy**: Weights are private inputs; only `model_root` is public
- **Input privacy**: Features are private; only `input_hash` is public
- **Output integrity**: `output` is committed in journal; verifier checks it
- **Replay protection**: `block_height` bound to proof
- **No float nondeterminism**: All arithmetic is integer fixed-point
