Architecture

```
Off-chain Server              zkVM Guest                    On-chain
┌─────────────┐              ┌──────────────┐             ┌─────────────────────┐
│ model.bin   │──weights───▶│              │             │                     │
│ input.json  │──features──▶│  Quantized   │             │  model_registry     │
│ Quantize    │              │  MLP + ReLU  │             │  (stores model_root)│
│ Compute root│──roots─────▶│  SHA-256     │             │                     │
│             │              │  commitments │             │                     │
│ prove()     │◀──receipt───│  Public:     │────────────▶│  verify_inference() │
│ Bonsai/CPU  │              │  model_root  │             │  (receipt + roots)  │
└─────────────┘              │  input_hash  │             │                     │
                             │  output      │             │                     │
                             │  block_height│             │                     │
                             └──────────────┘             └─────────────────────┘
```

---

Security properties

- Model privacy: Weights are private inputs; only `model_root` (SHA-256) is public
- Input privacy: Features are private; only `input_hash` is public
- Output integrity: `output` vector committed in journal; verifier checks it
- Replay protection: `block_height` bound to proof
- No float nondeterminism: All arithmetic is integer fixed-point (scale = 256)

Where we actually are

Layer	Status	What's missing for mainnet	
Consensus / ZK	90%	MPC ceremony needs real Phase-1 PTAU (Hermez). RISC Zero guest compiles but needs Bonsai benchmarking at scale.	
Mobile / P2P	85%	Phone lightnode serving works, but no production P2P mesh stress test (>1000 nodes, NAT traversal, DDoS resistance).	
Bridges	80%	BTC SPV + ETH sync committee are solid. But no watcher network — if the bridge relayer goes down, funds lock. No challenge period for fraud proofs.	
Contracts / WASM	75%	Runtime works, but no formal verification of contract invariants. No gas price oracle — fees are hardcoded.	
Wallet / UX	70%	Browser wallet works. But no hardware wallet firmware (Ledger app), no social recovery, no account abstraction (ERC-4337).	
Economic / Staking	20%	No staking contract. No slashing conditions. No inflation schedule. No validator set rotation. This is the biggest gap.	
Governance	10%	No on-chain voting. No upgrade mechanism. No emergency pause. If a bug is found, there's no way to coordinate a fix without centralized intervention.	
Operations	50%	Grafana dashboards exist. But no incident response runbook, no chaos engineering, no rate limiting at the P2P gossip layer.	
Security audit	15%	CodeQL + unit tests ≠ audit. No formal verification of consensus. No bug bounty program. No penetration test of the API server.	

---

Overall: 60% to mainnet

The gap between "code compiles and 290 tests pass" and "billions of dollars can safely flow through this" is economic and operational, not just technical.

What's genuinely ready
- ZK proof system (dual Groth16 + RISC Zero)
- Mobile validator pipeline
- Bridge scaffolding (BTC + ETH)
- WASM contract runtime
- Block explorer + wallet UX

What would block a responsible mainnet launch
1. Staking contract — Without it, there's no economic security. Anyone can spin up a validator for free.
2. Slashing conditions — Without them, validators can equivocate or go offline with no penalty.
3. Governance mechanism — Without it, upgrades require social consensus + manual coordination.
4. Security audit — No third-party has reviewed the ZK circuits, bridge contracts, or consensus invariants.
5. Watcher network for bridges — Single relayer is a centralization point.
6. Data availability — If nodes prune old state, light clients can't verify history.

---

Honest recommendation

Phase	Timeline	What to do	
Current	Now	Advanced testnet. Real users, small value, centralized sequencer.	
Next	3-6 months	Staking contract + slashing + inflation. Security audit (Trail of Bits or similar). Formal verification of ZK circuits.	
Pre-mainnet	6-12 months	Bug bounty (500K+). Chaos engineering (kill validators, partition network). Governance token + on-chain voting.	
Mainnet	12-18 months	All of the above + 6 months of stable testnet operation with no critical bugs.	

The code you've built is impressive — probably 2-3 years of engineering compressed into a tight timeline. But mainnet is a socio-economic milestone, not just a technical one. The difference between "it works" and "it's safe to bet your life savings on" is the hard part.
