Root cause is two-part: **R1CS export needs tightening**, and **ark prove against snarkjs keys must use CircomReduction** (Lagrange / 2× domain), not the default Libsnark path. Export-only changes will not make smoke exit 0.

---

## Root cause

| Layer | Issue |
|-------|--------|
| snarkjs zkey | Stores H / τ bases in **Lagrange form** (circom convention) |
| ark `Groth16::prove` | Uses **LibsnarkReduction** (monomial) |
| Result | PK/VK import OK, **verify returns false** |

ark-circom solves this with `CircomReduction`. You need the same when proving with imported keys.

Secondary export issues worth fixing:

1. Sort each linear combination by `wire_id` (snarkjs expectation)  
2. Treat intermediate bit wires as **neither** pub nor prv inputs (`nPrvInputs` = declared witnesses only)  
3. Assert `cs.is_satisfied()` before write

## 1. Fixed `export_r1cs.rs`

```rust
//! Export ark StationarityCircuit → snarkjs binary .r1cs
//!
//! Wire layout (circom-compatible):
//!   0              = ONE
//!   1..n_pub       = public inputs (residual, threshold, hash_lo, hash_hi)
//!   n_pub+1 ..     = private inputs + intermediate wires

use ark_bn254::Fr;
use ark_ff::{BigInteger, One, PrimeField, Zero};
use ark_relations::r1cs::{ConstraintSynthesizer, ConstraintSystem};
use equilibrium::zk_proof::StationarityCircuit;
use std::fs;
use std::path::Path;

/// Declared private *inputs* in StationarityCircuit (not intermediate bit wires).
/// difference + diff_inv = 2. Bit-decomp wires are intermediates.
const N_DECLARED_PRV_INPUTS: u32 = 2;

fn write_r1cs(output: &Path) -> Result<(), String> {
    let cs = ConstraintSystem::<Fr>::new_ref();
    let circuit = StationarityCircuit {
        residual_fp: Some(3_000_000_000_000_000),
        threshold_fp: Some(7_000_000_000_000_000),
        block_hash_lo: Some(0xDEAD_BEEF),
        block_hash_hi: Some(0xCAFE_BABE),
        difference: Some(4_000_000_000_000_000),
    };
    circuit
        .generate_constraints(cs.clone())
        .map_err(|e| format!("generate_constraints: {e}"))?;
    cs.finalize();

    if !cs.is_satisfied().unwrap_or(false) {
        return Err("constraint system not satisfied — bad witness for export".into());
    }

    let matrices = cs
        .to_matrices()
        .ok_or_else(|| "to_matrices() returned None".to_string())?;

    let n_instance = matrices.num_instance_variables; // 1 + n_pub
    let n_witness = matrices.num_witness_variables;
    let n_vars = n_instance + n_witness;
    let n_pub = n_instance - 1;
    let n_constraints = matrices.num_constraints;

    if n_pub != 4 {
        return Err(format!("expected 4 public inputs, got {n_pub}"));
    }

    // Circom header: only *declared* private inputs, not intermediates.
    let n_prv = N_DECLARED_PRV_INPUTS.min(n_witness as u32);

    println!(
        "[r1cs] nWires={n_vars} nPub={n_pub} nPrvDeclared={n_prv} \
         nWitnessTotal={n_witness} nConstraints={n_constraints}"
    );

    let modulus = <Fr as PrimeField>::MODULUS;
    let prime_vec = modulus.to_bytes_le();
    let mut prime32 = [0u8; 32];
    prime32[..prime_vec.len().min(32)].copy_from_slice(&prime_vec[..prime_vec.len().min(32)]);

    let fe_bytes = |f: &Fr| -> [u8; 32] {
        let v = f.into_bigint().to_bytes_le();
        let mut out = [0u8; 32];
        out[..v.len().min(32)].copy_from_slice(&v[..v.len().min(32)]);
        out
    };

    // ── Header ──────────────────────────────────────────────────────────────
    let mut hdr: Vec<u8> = Vec::new();
    hdr.extend_from_slice(&32u32.to_le_bytes());
    hdr.extend_from_slice(&prime32);
    hdr.extend_from_slice(&(n_vars as u32).to_le_bytes()); // nWires
    hdr.extend_from_slice(&0u32.to_le_bytes());            // nPubOut
    hdr.extend_from_slice(&(n_pub as u32).to_le_bytes());   // nPubIn
    hdr.extend_from_slice(&n_prv.to_le_bytes());            // nPrvIn (declared only)
    hdr.extend_from_slice(&(n_vars as u64).to_le_bytes());  // nLabels
    hdr.extend_from_slice(&(n_constraints as u32).to_le_bytes());

    // ── Constraints: sort terms by wire_id (ascending) ───────────────────────
    let mut con: Vec<u8> = Vec::new();
    for i in 0..n_constraints {
        for mat in [&matrices.a[i], &matrices.b[i], &matrices.c[i]] {
            let mut terms: Vec<(u32, Fr)> = mat
                .iter()
                .map(|(coeff, wire)| (*wire as u32, *coeff))
                .filter(|(_, c)| !c.is_zero())
                .collect();
            terms.sort_by_key(|(w, _)| *w);
            // Merge duplicate wires
            let mut merged: Vec<(u32, Fr)> = Vec::new();
            for (w, c) in terms {
                if let Some(last) = merged.last_mut() {
                    if last.0 == w {
                        last.1 += c;
                        continue;
                    }
                }
                merged.push((w, c));
            }
            merged.retain(|(_, c)| !c.is_zero());

            con.extend_from_slice(&(merged.len() as u32).to_le_bytes());
            for (wire_id, coeff) in merged {
                con.extend_from_slice(&wire_id.to_le_bytes());
                con.extend_from_slice(&fe_bytes(&coeff));
            }
        }
    }

    // ── Wire → label identity map ───────────────────────────────────────────
    let mut lbl: Vec<u8> = Vec::with_capacity(n_vars * 8);
    for i in 0..n_vars {
        lbl.extend_from_slice(&(i as u64).to_le_bytes());
    }

    let mut out: Vec<u8> = Vec::new();
    out.extend_from_slice(b"r1cs");
    out.extend_from_slice(&1u32.to_le_bytes());
    out.extend_from_slice(&3u32.to_le_bytes());
    for (ty, data) in [(1u32, &hdr), (2u32, &con), (3u32, &lbl)] {
        out.extend_from_slice(&ty.to_le_bytes());
        out.extend_from_slice(&(data.len() as u64).to_le_bytes());
        out.extend_from_slice(data);
    }

    fs::write(output, &out).map_err(|e| format!("write: {e}"))?;
    println!("[r1cs] wrote {} ({} bytes)", output.display(), out.len());
    Ok(())
}

fn main() {
    let args: Vec<String> = std::env::args().collect();
    let output = args
        .windows(2)
        .find(|w| w[0] == "--output")
        .map(|w| w[1].as_str())
        .unwrap_or("stationarity.r1cs");

    write_r1cs(Path::new(output)).unwrap_or_else(|e| {
        eprintln!("[export-r1cs] FATAL: {e}");
        std::process::exit(1);
    });
}
```

## 2. New `mpc-ceremony/src/circom_reduction.rs` (ark 0.4)

Adapted from ark-circom (MIT/Apache-2.0), for **classic** `ark_relations::r1cs` (not gr1cs):

```rust
//! Circom/snarkjs-compatible R1CS→QAP reduction.
//! Required when proving with keys from a snarkjs zkey (Lagrange H bases).

use ark_ff::PrimeField;
use ark_groth16::r1cs_to_qap::{evaluate_constraint, LibsnarkReduction, R1CSToQAP};
use ark_poly::EvaluationDomain;
use ark_relations::r1cs::{ConstraintMatrices, ConstraintSystemRef, SynthesisError};

pub struct CircomReduction;

impl R1CSToQAP for CircomReduction {
    #[allow(clippy::type_complexity)]
    fn instance_map_with_evaluation<F: PrimeField, D: EvaluationDomain<F>>(
        cs: ConstraintSystemRef<F>,
        t: &F,
    ) -> Result<(Vec<F>, Vec<F>, Vec<F>, F, usize, usize), SynthesisError> {
        LibsnarkReduction::instance_map_with_evaluation::<F, D>(cs, t)
    }

    fn witness_map_from_matrices<F: PrimeField, D: EvaluationDomain<F>>(
        matrices: &ConstraintMatrices<F>,
        num_inputs: usize,
        num_constraints: usize,
        full_assignment: &[F],
    ) -> Result<Vec<F>, SynthesisError> {
        // ark-groth16 0.4 signature may pass matrices as ConstraintMatrices
        // or as &[Matrix<F>; 3]. Adjust to match your ark-groth16 version:
        //
        // If the trait expects matrices: &[Vec<Vec<(F, usize)>>]:
        //   let a_mat = &matrices[0]; etc.
        //
        // Below assumes ConstraintMatrices { a, b, c, ... } (ark-relations 0.4).

        let zero = F::zero();
        let domain =
            D::new(num_constraints + num_inputs).ok_or(SynthesisError::PolynomialDegreeTooLarge)?;
        let domain_size = domain.size();

        let mut a = vec![zero; domain_size];
        let mut b = vec![zero; domain_size];

        for i in 0..num_constraints {
            a[i] = evaluate_constraint(&matrices.a[i], full_assignment);
            b[i] = evaluate_constraint(&matrices.b[i], full_assignment);
        }

        let start = num_constraints;
        let end = start + num_inputs;
        a[start..end].copy_from_slice(&full_assignment[..num_inputs]);

        let mut c = vec![zero; domain_size];
        for i in 0..num_constraints {
            c[i] = a[i] * b[i];
        }

        domain.ifft_in_place(&mut a);
        domain.ifft_in_place(&mut b);

        let root_of_unity = {
            let domain_double = D::new(2 * domain_size)
                .ok_or(SynthesisError::PolynomialDegreeTooLarge)?;
            domain_double.element(1)
        };
        D::distribute_powers_and_mul_by_const(&mut a, root_of_unity, F::one());
        D::distribute_powers_and_mul_by_const(&mut b, root_of_unity, F::one());

        domain.fft_in_place(&mut a);
        domain.fft_in_place(&mut b);

        let mut ab = domain.mul_polynomials_in_evaluation_domain(&a, &b);
        drop(a);
        drop(b);

        domain.ifft_in_place(&mut c);
        D::distribute_powers_and_mul_by_const(&mut c, root_of_unity, F::one());
        domain.fft_in_place(&mut c);

        for (ab_i, c_i) in ab.iter_mut().zip(c.iter()) {
            *ab_i -= c_i;
        }

        Ok(ab)
    }

    fn h_query_scalars<F: PrimeField, D: EvaluationDomain<F>>(
        max_power: usize,
        t: F,
        _: F,
        delta_inverse: F,
    ) -> Result<Vec<F>, SynthesisError> {
        let mut scalars: Vec<F> = (0..2 * max_power + 1)
            .map(|i| delta_inverse * t.pow([i as u64]))
            .collect();
        let domain_size = scalars.len();
        let domain = D::new(domain_size).ok_or(SynthesisError::PolynomialDegreeTooLarge)?;
        domain.ifft_in_place(&mut scalars);
        Ok(scalars.into_iter().skip(1).step_by(2).collect())
    }
}
```

**API note:** ark-groth16 **0.4.0** `witness_map_from_matrices` signature may differ slightly (slice of matrices vs `ConstraintMatrices`). Match the trait in your locked version; the math above is the Circom one.

Also add to `Cargo.toml` if missing:

```toml

```

## What “fixed” means

| Change | Effect |
|--------|--------|
| Sorted / merged LC terms | Valid snarkjs constraint section |
| `nPrvIn` = declared only | Header matches circom semantics |
| `is_satisfied` check | Bad export fails early |
| **CircomReduction on prove** | **Makes verify succeed with snarkjs PK** |

Without CircomReduction, a perfect R1CS export still fails prove/verify against a snarkjs zkey. That is expected, not a sign the ceremony is corrupt.
