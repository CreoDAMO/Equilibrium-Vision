Root Cause

503 in the arbitrage routes means `getArbitrageAddress()` returns `undefined`. The route handler does:

```ts
const address = getArbitrageAddress();
if (!address) return res.status(503).json({ error: "Arbitrage contract not deployed" });
```

The "dev mode — no ADMIN_KEY" describe block doesn't deploy the arbitrage contract before testing pause/unpause/set-model. The first describe block (read-only tests) calls `initChain()` which deploys it, but the second describe block either:
1. Uses a fresh app instance without `initChain()`
2. Shares module state that gets cleared between describe blocks
3. Has a `beforeAll` that intentionally skips deployment for "dev mode" testing but forgot to mock the address

This is a test setup bug, not a code bug. The stress tests prove the arbitrage contract works correctly — they exercise pause, unpause, set-model, and circuit breaker extensively.
