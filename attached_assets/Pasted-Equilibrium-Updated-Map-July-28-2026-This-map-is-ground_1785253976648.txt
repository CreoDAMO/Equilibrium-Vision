What “Fully Mobile Blockchain” Means

A fully mobile blockchain must satisfy:

Requirement Equilibrium’s Status
Consensus and mining run on mobile CPUs ✅ Proof-of-Stationarity is CPU‑only – no ASICs, no GPUs. The solver runs on a phone in milliseconds.
Full node software runs on mobile devices ✅ The entire node stack (libp2p, SMT, state machine, WASM VM) is compiled to Android via the JNI bridge and p2p_runtime.rs.
Peers discover each other without central servers ✅ mDNS (Wi‑Fi), Kademlia DHT, and QR/NFC invites eliminate the need for seed nodes.
Sync and state verification are trust‑minimised ✅ SMT state roots and compact proofs allow light nodes to verify state without trusting a server.
The network can operate without any cloud or VPS ✅ Two phones can form a network, mine blocks, and propagate them entirely over libp2p without a single HTTP call.
Mobile devices are first‑class peers, not just clients ✅ Phones serve tip and block data to other phones via light‑node and sync RR protocols.
